# Recap designs

Reference designs for the recap redesign. The recap is a sequence of
full-screen cards, like stories: a segmented progress bar at the top, a close
button, and one idea per card. Each file is one card at phone width (390 px).

Completed arc, in order:
01 you showed up · 02 your intention · 03 longest streak · 04 toughest week ·
05 what you did · 06 along the way (milestones) · 07 the whole season · 08 what next

Failed (strict) arc: 09 replaces 01 ("You made it to day N"), 10 replaces 08.

How to read them: layout and copy are between <x-dc> and </x-dc>. Colour
tokens ({{c.ever}}, {{c.muted}}…) are defined in the <script> block at the
bottom (object P, light and dark) and match contract/design/tokens.json.
disc() shows how each day state is drawn (same as the Today designs).
Literata italic is only for the person's own words (intention, milestone
reflections). All numbers in these files are sample data.
